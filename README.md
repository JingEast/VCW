# 🎓 港籍升学热点文案批量生成器

基于优化后的 Prompt 框架实现的 Python 应用程序，包含**迭代记忆机制**和**信息时效性保障**，专为港籍升学领域教育博主设计，批量生成适合短视频/小红书/公众号的口播文案。

---

## ✨ 核心特性

| 特性 | 说明 |
|------|------|
| 🧠 **记忆机制** | 每次修改意见自动记录到记忆库，下次生成前自动查阅并规避历史问题 |
| ⏰ **时效性保障** | 自动检查并禁止过时政策、疫情期临时政策、模糊年份表述 |
| 🔍 **质量检查** | 生成后自动执行结构/语言/数据/时效性多维质检 |
| 🎯 **多模型支持** | 支持 OpenAI、DeepSeek、Kimi 等任意 OpenAI 兼容接口 |
| 💾 **自动存档** | 生成文案自动保存到 `data/generated/` 目录 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置 API Key

首次运行会自动创建 `config.json`，或手动创建：

```json
{
  "llm": {
    "provider": "openai",
    "api_key": "sk-xxxxxxxxxxxxxxxx",
    "base_url": "https://api.openai.com/v1",
    "model": "gpt-4o",
    "temperature": 0.7,
    "max_tokens": 2000
  }
}
```

**支持任意 OpenAI 兼容接口**，例如 DeepSeek：

```json
{
  "llm": {
    "api_key": "sk-xxxxxxxxxxxxxxxx",
    "base_url": "https://api.deepseek.com/v1",
    "model": "deepseek-chat"
  }
}
```

### 3. 运行程序

```bash
python run.py
```

## 📖 使用指南

### 生成文案流程

```
主菜单
  └── 1. 生成文案
        ├── 输入主题、受众、数据、政策要点等
        ├── 系统自动关联记忆库中的历史修改意见
        ├── LLM 生成文案
        ├── 自动质量检查（时效性/结构/语言）
        ├── 自动保存到 data/generated/
        └── 可选：记录本次修改意见到记忆库
```

### 记忆库工作流程

```
第1次生成
  → 文案有问题（如"数据过时"）
  → 用户输入修改意见
  → 存入 memory_db.json

第N次生成（同一主题）
  → 系统自动读取历史修改意见
  → 在 Prompt 中明确提示"请规避以下问题"
  → LLM 根据修正方案调整输出
```

### 质量检查覆盖项

| 检查类别 | 具体内容 |
|----------|----------|
| **时效性** | 禁止模糊年份（"近年来"）、标记老旧数据、排除疫情政策 |
| **结构** | 五段式完整性、行动号召是否存在 |
| **语言** | 去AI味（禁止学术连接词、机械排比） |
| **内容** | 具体学校名称数量、数据标注、元信息泄露 |

## 🛠️ 高级配置

### 记忆库配置

```json
{
  "memory": {
    "db_path": "data/memory_db.json",
    "max_entries_per_topic": 10
  }
}
```

### 输出配置

```json
{
  "output": {
    "save_dir": "data/generated",
    "auto_save": true
  }
}
```

### 严格模式

```json
{
  "quality_check": {
    "enabled": true,
    "strict_mode": false
  }
}
```

- `strict_mode: false`：warning 级别问题不阻止流程
- `strict_mode: true`：任何 warning 都视为未通过

## 💡 使用技巧

### 1. 充分利用记忆库
每次发现文案有问题时，**务必记录修改意见**。记忆库会按主题索引，同一主题积累越多，生成质量越稳定。

### 2. 数据时效性输入规范
在输入"核心数据"和"政策要点"时，**主动标注年份和有效期**，例如：

```
核心数据: DSE 2025年报考人数约5万人（考评局2025年4月公布）
政策要点: 内地高校招收港籍生最低录取要求（2024-2026学年有效）
```

### 3. 批量生成建议
如需批量生成多个主题，可在"额外要求"中指定：

```
额外要求: 请生成3个不同角度的变体，分别以"焦虑型""数据型""故事型"切入
```

## ⚠️ 重要提示

1. **AI 无法实时联网**：程序依赖 LLM 训练数据中的知识，对于 2026 年之后的最新政策变动，建议在输入变量中主动提供最新素材。
2. **记忆库需人工维护**：系统提供记忆框架，但修改意见的准确性依赖用户的输入质量。
3. **政策类文案务必人工复核**：涉及升学政策、分数线等关键信息，生成后请务必人工核实。
